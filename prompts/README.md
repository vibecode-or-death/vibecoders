# Промпты

Рабочие промпты, которые реально дали результат. Формат — из `CONTRIBUTING.md`.

## Правила

- Один промпт = один файл `короткое-название.md`.
- Обязательно указывай инструмент (Cursor, v0, Bolt, ChatGPT и т.д.).
- Добавляй пример результата: ссылку, скрин или описание.
- Если промпт требует контекста, положи его в тот же файл блоком «Контекст».

## Категории (добавляй в название)

- `api-` — backend и API
- `ui-` — интерфейсы
- `debug-` — поиск и исправление ошибок
- `deploy-` — деплой и инфраструктура
- `data-` — работа с данными

## Промпт-паки

Готовые наборы для конкретной задачи складывай в `packs/`.
