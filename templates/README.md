# Шаблоны проектов

Стартеры, которые можно склонировать и за час довести до рабочего прототипа.

## Структура шаблона

```
templates/название/
├── README.md       # что это, как запустить, что внутри
├── .env.example    # переменные без секретов
└── ...             # сам код
```

## Требования

- README с командами запуска (`install`, `dev`, `build`).
- `.env.example` вместо `.env`.
- Минимум зависимостей — шаблон должен подниматься быстро.
- Укажи, для какого инструмента оптимизирован (Cursor, v0, Bolt и т.д.).
