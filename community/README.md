# Проекты сообщества

Здесь собираем кейсы участников — то, что сделано за вечер, за выходные или за кофе.

## Формат

Файл `ник-проект.md`:

```markdown
# Проект — @ник

**Время:** сколько ушло
**Стек:** что использовал(а)
**Ссылка:** деплой или репозиторий

## Что получилось

## Что сработало

## Что было сложным
```

Кейсы из этой папки потом можно использовать как доказательство в закрепах Discord и на лендинге — с указанием авторства.
