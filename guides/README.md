# Гайды

Пошаговые инструкции и разборы. Один гайд = один файл `название-гайда.md`.

## Формат

```markdown
# Название

**Уровень:** новичок / средний / продвинутый
**Время:** сколько займёт
**Инструменты:** что понадобится

## Результат

Что получится на выходе (скрин или ссылка).

## Шаги

1. ...
2. ...

## Частые ошибки

- ...
```

## Идеи для первых гайдов

- От идеи до деплоя за 24 часа.
- Как писать промпт, который не ломает код.
- Ревью AI-кода: на что смотреть в первую очередь.
- Как собрать первый платящий продукт на выходных.
