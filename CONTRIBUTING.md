# Как внести вклад

Спасибо, что помогаешь развивать сообщество. Здесь всё просто.

## Процесс

1. Сделай форк репозитория.
2. Создай ветку от `main`:
   - `feat/название` — новый промпт, гайд, шаблон;
   - `fix/название` — исправление ошибки;
   - `docs/название` — правки документации.
3. Внеси изменение одним логическим коммитом.
4. Открой PR в `main` и опиши:
   - что добавил(а);
   - как проверил(а);
   - ссылку на результат, если есть (скрин, деплой, репо).

## Куда что класть

| Тип вклада | Папка | Имя файла |
|---|---|---|
| Промпт | `prompts/` | `короткое-название.md` |
| Промпт-пак | `prompts/packs/` | `название-пака.md` |
| Стартер проекта | `templates/` | `название/` с читаемым README |
| Гайд | `guides/` | `название-гайда.md` |
| Кейс участника | `community/` | `ник-проект.md` |
| Обновление целей | `goals/` | `ROADMAP.md` |

## Формат промпта

```markdown
# Название

**Инструмент:** Cursor / v0 / Bolt / ChatGPT / другое
**Для чего:** короткое описание задачи

## Промпт

```
...сам текст...
```

## Пример результата

Что получилось, ссылка или скриншот.

## Заметки

Подсказки, ограничения, что улучшить.
```

## Формат кейса

```markdown
# Проект — @ник

**Время:** сколько ушло
**Стек:** что использовал(а)
**Ссылка:** деплой или репозиторий

## Что получилось

## Что сработало

## Что было сложным
```

## Чего не делать

- Не коммить `.env`, токены, ключи и приватные данные — только `.env.example`.
- Не добавлять бинарники и тяжёлые файлы без необходимости.
- Не менять чужие файлы без связи с темой PR.
- Не рекламировать сторонние сервисы без согласования с командой.

## Вопросы

Задавай их в Discord сервера или в комментариях к PR — ответим.
