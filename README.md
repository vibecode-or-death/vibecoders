# Vibecoders HQ

Общий репозиторий сообщества вайбкодеров: промпты, шаблоны, гайды, кейсы и цели сервера.

> Строим продукты на ИИ и делимся тем, что работает. Открыто, по делу, без флера.

## Что тут лежит

| Папка | Что класть |
|---|---|
| `discord/` | Закреплённые посты, скрипт публикации, настройки сервера |
| `prompts/` | Рабочие промпты и промпт-паки |
| `templates/` | Стартеры проектов и шаблоны кода |
| `guides/` | Пошаговые гайды и разборы |
| `goals/` | Цели, воронка монетизации и дорожная карта |
| `community/` | Проекты участников и кейсы «сделал за вечер» |

## Быстрый старт

```bash
git clone <URL-этого-репозитория>
cd vibecoders
cat goals/ROADMAP.md      # куда мы идём
cat discord/README.md     # как закинуть посты в Discord
```

## Как внести вклад

1. Форк → ветка `feat/короткое-имя` → PR в `main`.
2. Один PR — одна тема (промпт, гайд, шаблон).
3. Проверь [CONTRIBUTING.md](CONTRIBUTING.md) и [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
4. В описании PR напиши, как проверял(а) и что получилось.

## Правила

- Никакого спама и рекламы без согласования.
- Показывай процесс, а не только результат.
- Не коммить токены и `.env` — только `.env.example`.
- Помогай другим: ревью и доработки приветствуются.
