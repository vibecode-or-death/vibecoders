# Закреплённые посты для сервера вайбкодеров

5 готовых embed-постов + скрипт публикации через вебхук. Без зависимостей, нужен Node.js 18+.

## Что внутри

| # | Пост | Куда закреплять |
|---|---|---|
| 1 | 📊 Дашборд целей | `#цели` — главный закреп с цифрами на 1 / 3 / 4 / 6 месяцев |
| 2 | 💰 Воронка монетизации | `#монетизация` — FREE → PRO → STUDIO → продукты → B2B |
| 3 | 🗺 Дорожная карта | `#планы` — 5 этапов и приоритет недели |
| 4 | 👋 Онбординг | `#добро-пожаловать` — правила и первые шаги |
| 5 | 🔥 Фокус недели | `#общий` — обновляешь каждую неделю и закрепляешь заново |

## Как запустить

1. В Discord: **Настройки сервера → Интеграции → Вебхуки → Новый вебхук**.
   Выбери канал, скопируй URL.
2. Скопируй `.env.example` в `.env` и вставь URL:

   ```bash
   cp .env.example .env
   ```

3. Отправь все посты:

   ```bash
   node send.mjs
   ```

4. В выводе будут ссылки на каждое сообщение — открой и **правый клик → Закрепить сообщение**.

## Полезные команды

```bash
node send.mjs --list        # показать список постов
node send.mjs --dry         # посмотреть JSON без отправки
node send.mjs 1 3           # отправить только посты №1 и №3
node send.mjs 5             # обновить фокус недели
```

> Если вебхук настроен на другой канал, просто поправь поле `channel` в `posts.json` — оно используется только как подсказка в выводе.

## Как править контент

Всё в `posts.json`. Структура каждого поста:

```json
{
  "key": "dashboard",
  "name": "Имя для вывода в консоли",
  "channel": "подсказка, куда закреплять",
  "payload": {
    "username": "Имя автора сообщения",
    "embeds": [ { ... }
```
Тело embed — стандартный формат Discord: `title`, `description`, `color` (десятичное число), `fields`, `footer`.
